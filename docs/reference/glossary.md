# Technical Glossary & Concepts

This glossary defines core concepts, terminology, algorithms, and architectural patterns used throughout the SkyOps platform.

---

### **Action Lease**
A distributed mutual-exclusion lock acquired by the control plane per cluster/namespace before dispatching a remediation mutation. Prevents concurrent, race-condition mutations from colliding on the same target workload.

### **Agent (`skyops-agent`)**
The lightweight Go daemon deployed as a single-replica Kubernetes Deployment in the `skyops-system` namespace. It observes cluster resources, scrapes metrics, spools data, executes approved mutations, and streams pod logs back to the control plane.

### **Atomic Rollback**
A guaranteed safety routine in the SkyOps remediation executor. If an applied mutation fails verification probes within the verification timeout window (default 60s), the agent immediately reapplies the pre-execution snapshot to revert the workload to its previous state.

### **Baseline Standard Deviation ($\mu \pm 2.5\sigma$)**
The statistical formula calculated by the SkyOps Intelligence Engine across historical metrics. Establishes normal operating bounds for CPU and memory usage, flagging spikes that exceed 2.5 standard deviations above the rolling mean as anomalies.

### **Blast Radius**
An analytical assessment of the downstream service dependencies and user impact caused by an incident. Computed by correlating service selectors, endpoints, ingress routes, and namespace topology.

### **Cluster Token (`skyops_at_...`)**
A 48-character cryptographic bearer token generated by the control plane upon cluster registration. Injected into the target cluster as a Kubernetes Secret and presented in the HTTP `Authorization` header of all agent outbound calls.

### **Control Plane**
The central SkyOps management server (`server.ts`) responsible for authenticating users, managing cluster entities, evaluating incident detection rules, coordinating Gemini AI analysis, and dispatching alert notifications.

### **Deterministic Incident Detection**
The architectural principle that alerts must be triggered solely by concrete, verifiable heuristic rules (exit codes, pod phase, probe status, node conditions), rather than non-deterministic LLM queries.

### **Fingerprint**
A deterministic SHA-256 hash computed from `ClusterID + Namespace + Kind + Name + IncidentType`. Used to deduplicate recurring failures into a single incident entity rather than generating multiple tickets across consecutive scrape cycles.

### **Informers & Watchers**
Kubernetes client-go constructs that maintain an in-memory cached view of cluster resources while streaming incremental delta events over long-lived HTTP chunked connections with `kube-apiserver`.

### **Metrics-Server (`metrics.k8s.io`)**
The official Kubernetes cluster resource metrics aggregator. Scraped by `skyops-agent` to ingest real-time CPU millicores and memory bytes for nodes and containers.

### **On-Demand Log Streaming**
An ephemeral log retrieval pipeline where pod logs are only queried from the Kubernetes API when an SRE operator opens an investigation, avoiding the bandwidth and storage cost of continuous cluster-wide log ingestion.

### **Protected Namespaces**
Critical system namespaces (`kube-system`, `kube-public`, `kube-node-lease`, `skyops-system`) where automated remediation actions are strictly prohibited to prevent damage to cluster infrastructure.

### **Remediation Autonomy Modes**
- **`MANUAL_ONLY`:** Proposals are generated for review; execution must be triggered manually outside of SkyOps.
- **`APPROVAL_REQUIRED`:** Remediation actions are queued until an authorized human SRE explicitly clicks "Approve & Execute" in the console.
- **`CONTROLLED_AUTONOMOUS`:** High-confidence, low-risk actions execute automatically within pre-configured rate limits and policy constraints.

### **Spool & Forward**
A resiliency pattern implemented in `agent/internal/spool/spool.go`. If the network connection to the control plane drops, telemetry records are persisted to a local disk FIFO buffer (`/var/spool/skyops-agent`), preventing memory exhaustion and data loss until connectivity is restored.

### **Strategic Merge Patch**
A Kubernetes-native JSON patching format that merges structured arrays and maps into existing resource specifications without overwriting unmanaged fields. Used by the agent to update container images or annotations.
